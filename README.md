# GoTrips Tourlead Bot

Telegram-бот для сбора отчётов турлидеров компании **GoTrips**.

## Что умеет

- Турлидер выбирает **направление тура** и **дату старта**, затем открывает отчёт
- В рамках открытого отчёта принимает любое количество сообщений:
  - 🎙 Голосовые (автоматически расшифровываются через Deepgram)
  - 📝 Текст
  - 📸 Фото и видео
  - 📎 Документы
- После нажатия «✅ Закрыть отчет» весь собранный материал отправляется в указанный Telegram-канал
- Турлидер получает подтверждение об отправке
- Поддержка whitelist — доступ только для своих сотрудников

## Направления туров

Дагестан, Дагестан 2.0, Абхазия, Грузия, ГрузияЭКС, Карелия, Питер+Карелия, Мурманск, Осетия, Китай, Малайзия, Камчатка, Узбекистан + произвольный ввод.

## Установка

```bash
git clone https://github.com/Stranger99b/gotrips-tourlead.git
cd gotrips-tourlead
pip install -r requirements.txt
cp .env.example .env
# Заполни .env своими токенами
```

## Настройка `.env`

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
REPORT_CHANNEL_ID=-1001234567890   # или @channel_name
DEEPGRAM_API_KEY=ключ_deepgram
ALLOWED_USER_IDS=123456789,987654321  # ID турлидеров через запятую
```

### Как получить нужные данные

| Параметр | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `REPORT_CHANNEL_ID` | Добавить [@JsonDumpBot](https://t.me/JsonDumpBot) в канал, переслать любое сообщение — ID будет в ответе |
| `DEEPGRAM_API_KEY` | [console.deepgram.com](https://console.deepgram.com) |
| `ALLOWED_USER_IDS` | Написать [@userinfobot](https://t.me/userinfobot) — ответит твой ID |

> Бот должен быть **администратором** канала с правом отправки сообщений.

## Запуск

```bash
./bot.sh start    # запустить в фоне
./bot.sh stop     # остановить
./bot.sh restart  # перезапустить
./bot.sh status   # проверить состояние
./bot.sh logs     # смотреть логи (tail -f)
```

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | Главное меню |
| `/cancel` | Отменить текущий открытый отчёт |
| `/myid` | Показать свой Telegram ID (для добавления в whitelist) |

## Маппинг направлений → темы канала

Хранится в `topics.json`. Ключ `_default` — тема для направлений не из списка.

```json
{
  "Дагестан": 2, "Дагестан 2.0": 3, "Абхазия": 4, "Грузия": 5,
  "ГрузияЭКС": 15, "Карелия": 8, "Питер+Карелия": 7, "Мурманск": 11,
  "Осетия": 6, "Китай": 9, "Малайзия": 10, "Камчатка": 13,
  "Узбекистан": 12, "_default": 60
}
```

Для перенастройки тем используй `get_topics.py` (бот должен быть остановлен).

## Добавление нового турлидера

1. Турлидер пишет `/myid` — получает свой ID
2. Добавить ID в `.env`: `ALLOWED_USER_IDS=...,новый_id`
3. `./bot.sh restart`
